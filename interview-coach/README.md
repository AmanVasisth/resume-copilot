# CareerCoach AI — Interview Intelligence MVP

CareerCoach AI is an adaptive interview and professional communication coach for IT, Data, BI and AI professionals.

## V1 promise
Prepare for a specific interview using a resume, job description, target role, seniority and candidate-selected focus. The engine creates an interview blueprint, asks adaptive technical/project/behavioral questions, evaluates answers, and stores weaknesses for future practice.

## V1 is NOT
- A generic chatbot
- A copied interview-question database
- A HackerRank clone
- A live interview cheating tool

## First target roles
Data Analyst, BI Developer, Power BI Developer, Qlik Developer, Data Engineer, AI/ML Engineer.

## Core differentiator
Resume Proof + Adaptive Depth + Persistent Weakness Memory.

## Build order
1. Interview blueprint API
2. Text interview loop
3. Resume/JD parsing
4. Technical competency engine
5. Answer evaluation
6. Persistent candidate memory
7. Voice input/output
8. Payments and usage limits
9. Enterprise/admin layer
